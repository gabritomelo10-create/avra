Conectar ao site

As alterações são gravadas no arquivo data/lotes.json do repositório do site no GitHub. Para publicar, cole um token de acesso do GitHub com permissão de escrita neste repositório. O token fica só neste navegador.

Como criar o token (uma vez só)
  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token.
  2. Em Repository access, escolha Only select repositories e marque gabritomelo10-create/avra.
  3. Em Permissions → Repository permissions, defina Contents como Read and write.
  4. Gere o token, copie e cole acima. Quem não tiver o token não consegue alterar nada.
